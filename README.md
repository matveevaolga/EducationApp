В данном репозитории представлено Desktop приложение для изучения программирования на Python **“LearnToCode”**, разработанное в рамках курсового проекта.

**Основные особенности приложения:**
1) Поддержка пользователей в изучении программирования на языке Python
2) Возможность решения и создания (только пользователи с правами администратора) упражнений
3) Возможность добавления понравившиеся упражнений в избранное
4) Возможность установить сложность задачи при её создании
5) Геймификация через систему опыта (exp получается при решении упражнений)
6) Возможность следить за своим прогрессом в профиле с помощью статистики в профиле пользователя
7) 4 типа упражнений: "Написать код", "Вписать свой ответ", "Выбрать верное" и "Вставить пропущенное"

**Основные технологии:**
1) GitHub: управление версиями приложения
2) MySQL: реализация базы данных
3) Visual Studio: среда разработки клиентской части приложения
4) WPF: фреймворк для разработки клиентской части приложения
